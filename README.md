# Car Price Prediction Using Python

## Project Description

Car Price Prediction is a Machine Learning project developed using Python to predict the selling price of a used car based on various features such as car name, year, present price, kilometers driven, fuel type, seller type, transmission, and owner.

The project uses data preprocessing, exploratory data analysis, and machine learning techniques to build a prediction model. The trained model can estimate the expected price of a car based on the provided input features.

## Objectives

* Predict the selling price of used cars.
* Analyze the factors that affect car prices.
* Perform data preprocessing and exploratory data analysis.
* Train and evaluate a machine learning model.
* Provide accurate price predictions for new car data.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning

The project follows these steps:

1. Load the car price dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Select important features.
5. Split the dataset into training and testing sets.
6. Train a machine learning regression model.
7. Evaluate the model using suitable performance metrics.
8. Predict the price of a car using new input data.

## Features Used
